# ihc

## Descrição
Implementamos uma tela da nossa aplicação onde o motorista pode verificar algumas estatísticas e a viagens que tem para o dia atual

## Como executar
### Executar no bash
```
python -m http.server 8080
```

E acessar http://127.0.0.1:8080/
